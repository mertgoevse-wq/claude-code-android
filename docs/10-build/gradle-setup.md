# Gradle setup

The build itself: wrapper, settings, root project, and the properties that vary between machines. Every command in this section assumes the wrapper, never a system Gradle.

## The toolchain

| Component | Version | Why this version |
|---|---|---|
| Gradle | 8.11.1 (wrapper-pinned) | Required by AGP 8.9; the wrapper is committed so nobody's local Gradle matters |
| Android Gradle Plugin | 8.9.1 | Current stable line for the target SDK below |
| Kotlin | 2.1.20 | K2 is the default compiler; the Compose compiler plugin ships with it |
| Compose Compiler plugin | `org.jetbrains.kotlin.plugin.compose` 2.1.20 | Versioned with Kotlin, not separately |
| Compose BOM | 2025.05.00 | Pins the whole Compose surface to one tested set |
| JDK | 21 (Temurin) | Required by AGP 8.9 and by K2 |
| compileSdk / targetSdk | 35 | The current Play requirement for new submissions |
| minSdk | 26 | Below 8.0 the process and storage model is materially different; see `14-build-plan/risk-register.md` |
| NDK | 27.1.12297006 | Only for the small native helper; see below |

`gradle/libs.versions.toml` is the single source of truth. No version string appears in a build script.

## Wrapper

```bash
# gradle/wrapper/gradle-wrapper.properties — committed
distributionBase=GRADLE_USER_HOME
distributionPath=wrapper/dists
distributionUrl=https\://services.gradle.org/distributions/gradle-8.11.1-bin.zip
networkTimeout=10000
validateDistributionUrl=true
zipStoreBase=GRADLE_USER_HOME
zipStorePath=wrapper/dists
```

`gradle-wrapper.jar` is committed. The `gradlew` scripts are committed and executable. `./gradlew --version` must work on a machine that has never seen this repository and has no system Gradle — that is the definition of the wrapper working.

## Gradle properties

`gradle.properties` — shared, safe to commit:

```properties
org.gradle.jvmargs=-Xmx4g -XX:MaxMetaspaceSize=1g -Dfile.encoding=UTF-8
org.gradle.parallel=true
org.gradle.caching=true
org.gradle.configuration-cache=true
org.gradle.configuration-cache.problems=warn

kotlin.code.style=official
kotlin.incremental=true

android.useAndroidX=true
android.nonTransitiveRClass=true
android.defaults.buildfeatures.buildconfig=false
android.defaults.buildfeatures.resvalues=true
android.defaults.buildfeatures.shaders=false

ksp.incremental=true
```

`android.defaults.buildfeatures.buildconfig=false` is set globally so `BuildConfig` is opt-in per module. It keeps generated constants from quietly spreading.

`local.properties` — machine-specific, never committed, and listed in `.gitignore`:

```properties
sdk.dir=/home/you/Android/Sdk
# optional, for manual-key builds only
manualKey=
```

`keystore.properties` — release signing, generated by the release pipeline, never committed:

```properties
storeFile=/path/to/release.jks
storePassword=…
keyAlias=…
keyPassword=…
```

## The configuration cache

Enabled. That is a discipline, not a convenience: **no build script may read an environment variable, call `System.getenv()`, or touch the filesystem outside the project at configuration time.** Anything that needs machine-specific input goes through a lazily-read provider.

`./gradlew help --configuration-cache` must report no problems. A warning is treated as a failure in CI (`--configuration-cache-problems=fail`).

## Native code

The app ships a small NDK helper — currently just the `run-as`-style process supervisor shim and a `getrandom` fallback for older API levels. It is one CMake target:

```
app/src/main/cpp/CMakeLists.txt
  target: ccandroid  (STATIC)
  languages: C, C++
  abiFilters: arm64-v8a, armeabi-v7a, x86_64
  minSdk: 26
```

The Claude Code binary itself is **not** built from source and **not** bundled in the APK. It is downloaded, checksum-verified, and patched at runtime — see `06-runtime/native-profile.md`. That is what keeps the APK under 25 MB.

The native helper has one CTest-style check target run from `./gradlew :app:externalNativeBuildCheck`, and its symbols are on the `readelf -s` allowlist so an unexpected JNI export is visible.

## Build cache and CI

| Setting | Value |
|---|---|
| Local build cache | `~/.gradle/caches/build-cache-1` |
| Remote cache | GitHub Actions cache, keyed on the lockfile hash and the wrapper hash |
| Build cache size, CI | 10 GB, evicted by LRU after 7 days |
| Deprecation warnings | `allWarning As Error` in CI, not locally |

## What a fresh clone must achieve

```bash
git clone <repo> && cd claude-code-android
./gradlew --version            # works, no system Gradle
./gradlew :app:assembleDebug   # produces an installable APK
./gradlew check                # lint, detekt, tests, screenshot diff
```

`docs/10-build/local-build-and-run.md` has the full command list with expected output.
